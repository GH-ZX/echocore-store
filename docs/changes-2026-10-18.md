# ECHOCORE Store: what changed (18 Oct 2026)

## 1. Security hole closed (most important)
- A database change on 21 Sep accidentally let any logged-in customer run internal "server-only" actions directly.
- With it, someone could have:
  - marked an unpaid ShamCash/Syriatel order or recharge as paid, so they got goods or balance for free;
  - marked orders as delivered or failed;
  - sent a notification to every customer;
  - read everyone's recharge history.
- It is fixed. Those actions now work only from the server.
- **Did anyone use it?** We checked every order, recharge and invoice and found no sign of abuse. Every credited recharge has a matching paid invoice.
- Other security fixes:
  - A fake "admin" login token was accepted by the supplier function. It is now rejected.
  - Anyone could send a fake "order completed / failed" message from the supplier. The store now checks the real status with G2Bulk first.
  - Customers could remove their own ban or mark themselves as verified. They can't anymore.

## 2. Fixes that protect sales
- **Buying several codes:** buying 2 codes of the same product (e.g. Valorant Riot Cash Turkey) bought only 1 and showed it twice on the receipt. Fixed: the quantity is now sent as one supplier order, so the customer gets the right number of different codes. Carts with different products buy each one separately.
- **Supplier outage:** if the G2Bulk website is down during the daily sync, the store now stops the sync. Before, it could switch all products off.
- **Daily sync:** it now updates the games you actually selected. Before, it could update the wrong ones.
- **"Payment sent" orders:** opening the Orders tab no longer cancels orders that customers reported as paid.
- **Duplicate payments:** a duplicate payment confirmation from Sam can no longer deliver an order twice.
- **Telegram bot:** it was rejecting every message from Telegram because it checked the wrong header. It works again.

## 3. Prices
- **New option "Price rounding"** (Admin → APIs → G2Bulk, below the markup). It rounds prices up to a tidy number, for example $1.08 becomes $1.10.
  - Choices: off, $0.05, $0.10, $0.25, $0.50 or $1.
  - It never lowers a price, and it never changes fixed-price or sale packs.
  - Press **Apply to prices now** to use it right away. The old prices are saved first, and **Undo last price update** brings them back.
- **Rounding bug fixed:** some prices were 1 cent too high (for example $1.11 instead of $1.10).

## 4. Admin dashboard
- **Overview warning:** "revenue without supplier cost" ($37.41) came from a Roblox order whose pack was later switched off by the sync. The order was fine. The dashboard now finds the cost of switched-off packs too.
- **Sync page on mobile:** buttons are full width and easier to tap, and long text no longer goes off the screen.

## 5. Look of the site
- The home page carousel now uses new wide images, so the art is no longer cropped.
- Product cards keep the original square images.
